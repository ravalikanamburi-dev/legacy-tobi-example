# Source file inventory

The machine-readable inventory is `source-file-inventory.csv`. This page records the counting method and the disposition values.

| Requirement | Meaning |
| --- | --- |
| program-spec | A dedicated specification under `docs/programs/` |
| data-entry | A section in `docs/database/database-object-catalog.md` |
| component-entry | A section in `docs/architecture/component-catalog.md` |
| existing-doc | The Markdown file is itself the document |
| disposition-only | Recorded in the inventory. No separate specification, because the file is build metadata, a manifest, or prose |
| not-applicable | Binary or IDE state |

Processing status `Completed` means the disposition above was written in this run. It does not mean every business question is answered.
